# AI-Powered Food Waste Prediction

This project predicts food wastage using Machine Learning.

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- HTML/CSS
- Chart.js

## Features
- AI Prediction
- Risk Analysis
- Doughnut Analytics Chart
- Responsive UI
- AI Insights

## Run Project

pip install -r requirements.txt

python app.py
